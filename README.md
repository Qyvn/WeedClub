# FYNBOS — South Africa Cannabis Dispensary

Premium B2C + B2B cannabis ecommerce demo for South Africa, with memberships.

## Features

- **B2C shop** — retail flower, oils, edibles, and accessories (ZAR)
- **B2B wholesale** — trade account application, case pricing, minimum orders
- **Memberships** — Leaf, Protea, and Baobab tiers with live cart discounts
- **Cart** — mixed retail + wholesale lines and demo checkout

## Stack

- React + TypeScript (Vite)
- Tailwind CSS v4
- React Router
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Adults 18+ only. This is a front-end demonstration, not a live licensed storefront.
